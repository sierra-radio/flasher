Before you start

  1. Use Google Chrome or Microsoft Edge on a Windows, Mac, Linux or ChromeOS computer. Phones and tablets won't work.
  2. Connect the ROIP board to the computer with a USB data cable.
  3. Click Install firmware below, choose the board's port from the list, and follow the prompts.
  4. Leave the cable connected until the page says the install is finished.
This browser can't talk to USB devices. Open this page in Google Chrome or Microsoft Edge on a computer.
This page must be opened over a secure (https://) address.
Updating a board that's already set up? When asked whether to erase the device, choose No. Erasing wipes your saved settings (IP address, password, codec).

Help

The board doesn't appear in the list

Try a different USB cable (some are charge-only) or another USB port. On Windows, install the Silicon Labs CP210x driver, then unplug and reconnect the board.

The install fails to connect

Hold the board's BOOT button, tap RESET, release BOOT, then click Install firmware again.

Changing settings after installing

After the install, choose Logs & Console to open a serial console in your browser and type the usual setup commands.
