How it works

  1. Make sure you pick the firmware for your product. Installing another product's firmware won't work.
  2. Click Install next to the version you want.
  3. Pick your device from the list of ports and click Connect.
  4. When asked whether to erase the device, either answer is fine.
  5. Wait for the install to finish. Don't unplug the device until it says it's done.
  6. Installing resets the device's saved settings, so set it up again afterwards. On the ROIP Device, type //setup in the serial console, or hold the mode button while powering up to use the Wi-Fi setup page from your phone (rev 72 and later).

No port in the list?

Try another USB cable (some only charge) or another USB port, and close any other program that's connected to the device.
